# Iron Nest: Artillery (Forge 1.20.1)

Управление орудием:
- снаряд в руке — зарядить
- пустая рука — угол возвышения (20/40/60/80°)
- пустая рука + Shift — повернуть орудие
- красный камень или огниво — выстрел

Рецепты: орудие — 4 железных слитка + поршень + раздатчик + 3 железных блока
(III / PDI / BBB); снаряды (x2) — железный слиток + 2 пороха.

Сборка: проще всего скачать Forge MDK 1.20.1 (47.x) с files.minecraftforge.net,
скопировать в него папку src/ и build.gradle из этого проекта, затем:
  ./gradlew build
Готовый jar будет в build/libs/. Нужна Java 17.
